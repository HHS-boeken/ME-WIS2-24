# 3.3 Combinaties van limieten

````{admonition} Theorie
:class: tip, dropdown open


```{admonition} Overzicht van combinaties
:class: warning

|                    |                   |       | |
|--------------------|-------------------|------|---|
| $\infty + \infty = \infty $ | $ 0 + 0 = 0 $ | $ 0 + \infty = \infty $ | $ \dfrac{L}{\infty} = 0  $
| $\infty \cdot \infty = \infty  $ | $ 0 \cdot 0 = 0 $ | $ 0 \cdot \infty = ? $ | $ \dfrac{\infty}{L} = \pm \infty (L \neq 0) $
| $\infty - \infty = ? $ | $ 0 - 0 = 0 $ | $\dfrac{\infty}{0} = +\infty \quad of -\infty$ | $\infty \pm L = \infty$ |
| $\dfrac{\infty}{\infty} = ?   $ | $\dfrac{0}{0} = ?$ | $\dfrac{0}{\infty} = 0$ | $\infty \cdot L = \pm \infty (L \neq 0)$ |

```

```{admonition} Dominante functies
:class: warning

1.  Het gedrag van een *exponentiële functie* is **dominant** over het gedrag van een *machtsfunctie*.
1.  Het gedrag van een *machtsfunctie* is **dominant** over het gedrag van een *logaritmische functie*.

```
````
